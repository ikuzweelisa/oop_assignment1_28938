# Assignment 1

## AUCA Student Management System
>AUCA intends to replace manual student, staff, course, timetable, assessment, fee and library records with a
console-based School Management System. Develop a complete OOP

## Compile
```bash
 javac -d bin $(find src -name "*.java")            
```
## Run

```bash
java -cp bin com.auca.main.Main
```
